# Task Manager

A simple web-based task management application.

## Features

- Add tasks
- Delete tasks
- Edit tasks
- Dashboard

## Technologies Used

- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Usage

1. Enter a task in the input box.
2. Click **Add Task**.
3. Use the available options to manage your tasks.
